## 2024-05-20 - [Fix Weak Random Number Generation for Image Uploads]
**Vulnerability:** The application used `Math.random().toString(36).substring(7)` to generate unique filenames for user-uploaded order images in `components/order-form/hooks/useOrderSubmit.ts`.
**Learning:** `Math.random()` is not a cryptographically secure pseudorandom number generator (CSPRNG). Using it for security-sensitive operations like generating unique identifiers or filenames can lead to predictable patterns, potentially allowing attackers to guess file paths, overwrite existing files, or gain unauthorized access to data. This pattern of using `Math.random()` for uniqueness is a common anti-pattern in JavaScript.
**Prevention:** Always use cryptographically secure methods for generating random identifiers. `crypto.randomUUID()` is natively supported in modern JavaScript environments (browsers and Node.js) and provides a secure, collision-resistant UUID v4, making it the ideal choice for generating unique filenames or identifiers.
