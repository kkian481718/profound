## 2023-10-24 - [Path Traversal in File Upload Extension]
**Vulnerability:** A path traversal vulnerability was discovered in the file upload mechanism for order images. The file extension was taken directly from user input (`image.name.split(".").pop()`) without sanitization, and appended to the file path. A malicious user could provide a filename like `test.jpg/../../evil` resulting in a file extension of `jpg/../../evil`. When this was combined with the storage path, it resulted in a path traversal vulnerability. Also, `Math.random()` was used for generating filename parts.
**Learning:** Never trust the file extension from a user-uploaded file name. The `.pop()` operation does not guarantee the returned string is a valid or safe extension. It can still contain directory traversal characters like `/` or `\\` if the original file name contains them.
**Prevention:** Sanitize the extracted file extension to allow only alphanumeric characters using a regex like `/[^a-zA-Z0-9]/g`. Furthermore, always use cryptographically secure random number generators (like `crypto.randomUUID()`) when generating filenames or identifiers.
