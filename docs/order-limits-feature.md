# 訂單限制功能說明

## 功能概述

本次更新為訂購表單添加了以下功能：

### 1. 全域訂單進度條

- **位置**: 顯示在訂購表單的最上方
- **功能**: 顯示今日全站訂單使用狀況
- **內容包括**:
  - 今日已下單數量 / 總限制數量
  - 進度條視覺化顯示
  - 剩餘名額數量
  - 狀態標示（可接單/接近滿額/已滿額）
  - 相應的警告訊息

### 2. 店家名額顯示

- **位置**: 顯示在個別店家資訊卡中
- **功能**: 顯示該店家今日訂單使用狀況
- **內容包括**:
  - 店家已接單數量 / 店家限制數量（若有設定）
  - 進度條視覺化顯示
  - 剩餘名額數量
  - 狀態標示和警告訊息
- **注意**: 若店家沒有設定名額限制，則不顯示此區塊

## 視覺設計

### 顏色系統

- **綠色 (success)**: 名額充足，可安心下單
- **橙色 (warning)**: 接近滿額（達80%以上），建議盡快下單
- **紅色 (danger)**: 已達上限，無法下單

### 進度條特效

- 使用漸層色彩 (primary to secondary)
- 包含陰影效果
- 百分比顯示（精確到小數點後一位）

### 警告訊息

- 接近滿額: 橙色背景，提醒用戶盡快下單
- 已達上限: 紅色背景，通知用戶已無法下單

## 技術實現

### 新增檔案

1. `components/order-form/hooks/useOrderLimits.ts` - 訂單限制資料管理 hook
2. `components/order-form/GlobalOrderProgress.tsx` - 全域訂單進度條組件

### 修改檔案

1. `components/order-form/index.tsx` - 主訂購表單，加入進度條
2. `components/order-form/StoreInfoDisplay.tsx` - 店家資訊卡，加入店家名額顯示
3. `components/order-form/types.ts` - 加入 max_daily_orders 欄位
4. `components/order-form/hooks/useStores.ts` - 查詢加入 max_daily_orders 欄位

### 資料流程

1. 表單載入時自動查詢全域和店家限制資訊
2. 即時計算使用率和剩餘名額
3. 訂單提交成功後自動重新載入資料
4. 錯誤處理：查詢失敗時優雅降級，不影響基本功能

## 效能考量

- 使用 React hooks 進行資料管理，避免不必要的重複查詢
- 店家資訊只在選擇特定店家時才載入
- 包含 loading 狀態，提升用戶體驗
- 錯誤處理機制，確保功能穩定性

## 用戶體驗

### 資訊透明度

- 用戶可清楚看到目前名額狀況
- 有助於用戶做出更好的下單決策
- 減少因名額已滿而產生的挫折感

### 視覺回饋

- 進度條提供直觀的視覺化資訊
- 顏色編碼幫助用戶快速理解狀況
- 適當的警告訊息引導用戶行為

## 維護注意事項

1. 確保 Supabase 中的 `global_settings` 表有正確設定 `max_daily_orders`
2. 店家的 `max_daily_orders` 欄位為 nullable，null 代表無限制
3. 所有時間計算都使用本地時區的當日 00:00:00 到 23:59:59
4. 包含完整的錯誤處理，確保在資料庫查詢失敗時不會影響基本功能
