## 2025-02-25 - [Insecure Random Number Generation for Filenames]
**Vulnerability:** Found `Math.random()` being used to generate unique identifiers for uploaded image filenames (`components/order-form/hooks/useOrderSubmit.ts`). `Math.random()` is not cryptographically secure and the resulting sequence could be predictable, leading to potential filename collisions or allowing attackers to guess the names of uploaded files.
**Learning:** In a client-side context, relying on `Math.random()` for uniqueness or security (even for simple object keys if they are exposed) is a common anti-pattern. While this specific instance was just for uploaded image names, predictable filenames can still lead to security issues like object enumeration or overwriting if the upload path logic doesn't prevent it.
**Prevention:** Always use cryptographically secure methods for generating random identifiers, tokens, or filenames. In modern browser environments, `crypto.randomUUID()` provides a cryptographically secure pseudo-random number generator (CSPRNG) that is built-in and easy to use.
